# Day 3: qBraid Platform Demo: Lab, Credits, and Submitting to a QPU

Recorded September 16, 2026. Presented by Alex Van Bussum, qBraid.

This day has no notebook and no notes. It is a recorded walkthrough of the platform: launching Lab, how the hackathon credits work, and submitting a circuit from Lab to a QPU. The recording is the file in this folder, and it also streams on the [bootcamp page](https://clemsonquantum.com/events/workshops-and-seminars/sc-quantathon-v3-bootcamp-2026/).

Before you watch, create a free account at [account.qbraid.com](https://account.qbraid.com/) with the email you registered with, then launch Lab from the account dashboard. Accepted participants are added to the SC Quantathon v3 organization on qBraid, which is where the credits live; there is no access key to enter.
